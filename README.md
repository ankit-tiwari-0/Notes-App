# 📝 React Notes App

A simple Notes App built with **React.js** and **Tailwind CSS** to practice React fundamentals.

## 🚀 Features
- Add notes with title and details
- Display notes dynamically
- Delete notes
- Clean UI using Tailwind CSS

## 🛠 Tech Stack
- React JS
- JavaScript
- Tailwind CSS

## 📚 Concepts Practiced
- useState Hook
- onChange & onClick events
- Array state management
- Dynamic rendering with `.map()`
